## Verification boundaries

These are native ImGui/D3D11 WARP captures using synthetic fixtures at 1280 x 800
and 480 x 360. The discovery fixture lowers the amethyst minimum to one; it does
not change the production default of six. The images establish menu composition,
not live Minecraft scanning, in-world marker appearance or attach behavior.
They are review evidence, not shipping raster assets. No new shipping raster
asset requires provenance.

The implementation owner reports passing `smp_features`, `control_panel` and
JNI `runtime_profiles` checks; the latter completed in 88 seconds after expanding
the mutable-position fixtures across mapped profiles. Those tests were not
rerun for this documentation pass. The remaining regression run was still
pending at handoff; this document does not claim a final full-suite result.
The launcher was unavailable and no design detector ran. No live Minecraft run,
actual clipboard/waypoint use or GPU/mod compatibility check was performed.
Hover, focus, filter-disabled combinations, capacity and scan-error states are
supported by inspected source but are not separately pictured in these captures.
