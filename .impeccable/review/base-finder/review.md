## 3. Findings with severity and evidence

**No material findings.**

- **Pass — hierarchy and identity:** Desktop settings and disabled/empty captures retain the compact native hierarchy, rounded anthracite pane, restrained coral controls and amber marker swatch. The added widget follows Base ESP without changing the existing grid pattern.
- **Pass — controls and meaning:** The settings captures show separate kelp and amethyst switches, visible thresholds and scan controls. Source disables each clue's thresholds when its filter is off. The explanatory copy identifies counted amethyst stages, one count per kelp plant, the height cap, loaded-world limits, and the fact that natural growth is only a possible base clue.
- **Pass — small viewport and reachability:** Both 480 x 360 settings states retain the fixed Base Finder header, Enabled control and close action. The discoveries-small capture shows the reason, coordinates, Copy coordinates and Save waypoint together, followed by the persistence explanation. Partial content at the scrolling body's edge is normal scroll clipping, not inaccessible content. control_panel.cpp keeps the root at zero scroll and places content in its separate child; the UI fixture asserts header separation and bottom reachability.
- **Pass — discovery and disabled states:** Both discoveries captures clearly label the result Possible Base and show the clue counts and chunk coordinates. Both disabled/empty captures provide the enabling recovery text. Source also provides the enabled-but-empty recovery, no-filter prompt, discovery-limit guidance, scanner status/errors, clipboard action and waypoint-capacity feedback.
- **Pass — behavior linkage:** Source links the new widget and binding to the real enabled setting, scan request mask/radius/interval, world-scoped discoveries and amber marker renderer. Profile migration supplies disabled defaults and an unbound action to older complete profiles. Existing preference and panic fixture assertions include Base Finder.
