mcov - Quick start
==================

You only need mcov.exe. This guide is optional.
You can move or share the client folder.

1. Start Minecraft Java Edition.
2. Double-click mcov.exe.
3. Enter your license key and click "Verify license".
4. Select your Minecraft instance and click "Start client".
5. Switch to Minecraft. If fullscreen causes problems, use windowed mode.

An internet connection and an active mcov license are required.
Your key is not saved. Verify it again after restarting the launcher.
If verification fails, check your key, subscription and system clock, then retry.

INSERT  Open / close the menu
F6      Edit the HUD
END     Quit the client

If "Select JDK folder" appears:
Choose an installed 64-bit JDK matching Minecraft's Java version.
A JRE alone cannot connect the client. The client does not install Java.

Settings are saved in client-settings.ini beside mcov.exe.
Named profiles are saved in configs\<Name>.ini beside mcov.exe.
Under Settings > Configs, enter a name and click "Save config".
For an existing name, use "Overwrite config" to replace it.
To load a profile, select it and click "Load selected".
After copying a profile into configs, click "Refresh".
When moving the client, take client-settings.ini and configs with it.

Logs, your JDK selection and automatically prepared helper files are stored in:
%LOCALAPPDATA%\mcov
You do not need to place DLLs or tools beside mcov.exe.

To update, quit the old client with END, then replace mcov.exe.
If the client reports an outdated agent, restart Minecraft.

To share the client, send mcov.exe or mcov-client.zip.
The ZIP contains only mcov.exe and this START.txt.
